## 七、核心改动总结

| 改动 | 说明 |
|------|------|
| 🔄 **方块拆解** | 方块可拆回原材料 (冰→浮冰→蓝冰双向, 石英块→下界石英, 荧石→荧石粉 等) |
| 🔀 **双重路径** | 同一种拆解可用工作台**或**切石机 (紫水晶、下界石英、滴水石锥、海晶碎片 等) |
| 📈 **楼梯增产** | 6 方块 → **6** 个楼梯 (原版只有 4 个) |
| 🎨 **染色重染** | 任意颜色方块可重新染色 (混凝土粉末、混凝土、玻璃、玻璃板、陶瓦) |
| ♻️ **废料回收** | 粗矿块直接烧炼为矿物块；混凝土粉末烧炼为染色玻璃 |
| 🧹 **简化配方** | 堆肥桶用木板替代木半砖；遮光玻璃可直接用紫水晶块合成 |
